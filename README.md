## Bringing Generative Learning to Representation Learning

My research brings generative learning tools into self-supervised representation learning by treating the latter as a **distribution-matching problem**. **DM** develops this formulation; **FBDM** extends it through flow matching.

### Distribution Matching (DM)

**Recasting self-supervised learning as distribution matching opens the door to generative learning tools for representation learning.**

[Bringing Generative Learning to Representation Learning: Self-Supervised Transfer Learning as Distribution Matching](https://arxiv.org/abs/2502.14424)

[Paper](https://arxiv.org/abs/2502.14424) · [Code](https://github.com/vincen-github/DM)

### Flow-Based Distribution Matching (FBDM)
